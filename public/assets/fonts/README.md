# Font locali

Barlow e Barlow Condensed sono distribuiti con SIL Open Font License 1.1.
I file vengono serviti localmente: nessuna richiesta a Google Fonts durante la navigazione.

- Barlow: https://fonts.google.com/specimen/Barlow
- Barlow Condensed: https://fonts.google.com/specimen/Barlow+Condensed
- Progetto e licenza: https://github.com/jpt/barlow

I file sono in formato WOFF2, ridotti ai caratteri latini usati dal sito
(circa 20 KB ciascuno invece di 85 KB in TTF).
