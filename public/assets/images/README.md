# Fotografie della vetrina

Tutte le immagini pubbliche sono file locali, non hotlink o immagini incorporate
dai social.

- `logo-inter-club-brindisi.jpg`: logo del club. Viene usato anche come segnaposto
  finché il direttivo non carica le proprie foto.

Le foto del club si caricano dall’editor **Sito vetrina** (JPEG, PNG o WebP) e
vengono salvate con nomi casuali `club-upload-*` su questo server. Non vengono
inviate automaticamente a GitHub: per versionarle, un responsabile deve
includerle in un commit.
